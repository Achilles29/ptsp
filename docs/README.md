# Dokumentasi Perubahan PTSP

Dokumentasi pada folder ini dibuat untuk mencatat perubahan aplikasi, fungsi yang ditambahkan, file yang berubah, dan dampak ke database.

## Daftar Dokumen

- `2026-04-22-operasional-antrian.md`
  Ringkasan perubahan fitur jam operasional antrian, cara kerja, dan catatan implementasi.

- `2026-04-22-file-database-changes.md`
  Inventaris file yang berubah/baru dan tabel database yang berubah/baru.

- `../sql/2026-04-22_operasional_antrian.sql`
  Script SQL terpisah untuk diterapkan di server lain.

- `2026-04-22-email-verifikasi.md`
  Panduan modul pengaturan email verifikasi, alur resend, setup Gmail, dan catatan anti spam.

- `../sql/2026-04-22_email_verification_settings.sql`
  Script SQL terpisah untuk tabel pengaturan email dan cooldown resend verifikasi.
